① 先给结论

继续 · 目标换成"写得快"

【建议 1】太原本地，SQL 和 Python 是唯二有定价权的技能。 太原 58 条真实岗里，提到 SQL 的薪资中位 8.5K、没提的 5.5K；Python 同样 8.5K vs 5.5K。 不是多 500 块，是 +55%。学这两个，是在本地市场里唯一能直接改价的操作。
【建议 2】Python 是太原 → 一线落差最大的技能：36.2% → 63.1%（差 27 个百分点，统计显著）。 SQL 在太原已经 46.6%，属于"没有就出局、有了不加分"；Python 是"有了才够得着外面的岗位"。先学 Python。
【建议 3】立刻砍掉三件事：Excel 深挖、SPSS、机器学习。 Excel 在全样本里是负溢价（提到它的岗位中位 14.5K，没提的反而 16.0K）——它是默认项，不是卖点； SPSS 十年从 33% 崩到 5%；机器学习对无经验者溢价仅 +0.3K（15.8 vs 15.5），基本等于没有。

③ 12 周学习路径

时间预算：工作日每晚 1.5h（课后到熄灯前），周末半天 4h → 每周约 11h，12 周约 130h。 这 130 小时的目标不是"学完"，是产出 3 个能贴进简历的作品。学得完学不完不重要，作品必须有。

阶段 1 · SQL：从"会写"到"写得快"第 1–3 周 · 约 33h
学什么
窗口函数（ROW_NUMBER / RANK / LAG）、CTE、自连接、行列转换； 三条业务模板必须闭眼能写：留存率、漏斗转化、环比/同比。
用什么
本机 MySQL 的 sqlpractice 库（已建好，student/score/course/employee 四表）+ Obsidian SQL 库现有笔记。零成本。
验收（做不到就别进下一阶段）
不看资料、20 分钟内写出「近 7 日新用户的次日留存率」，结果能自己解释清楚。
产出
Obsidian SQL 库里 5 篇笔记状态从 🟡 转 🟢；一条能贴进简历的留存分析 SQL。
逐日安排
见 阶段1-SQL进阶21天.html：15 个练习日、每题都有在本机实测过的参考答案。
阶段 2 · Python（pandas）：把已有数据重做一遍第 4–7 周 · 约 44h
学什么
pandas 读 CSV / 清洗缺失与重复 / groupby / merge / 透视表；matplotlib 出柱状图与折线图。只学这些，不碰 sklearn。
捷径（关键）
不要另外找练习数据。直接把这次 328 条 JD 的分析用 pandas 重写一遍 —— 数据现成（data/jd_dataset_v3.csv）、结论已知、错了能立刻发现。学工具的同时产出作品，一举两得。
验收
一个 100 行以内的脚本完成：读 csv → 清洗 → 按城市分组统计技能率 → 出图 → 存结果文件。
产出
作品集 #3：JD 技能分析的 Python 复现版（脚本 + 图表 + 一页说明）。
阶段 3 · BI 看板：把分析做成能讲的东西第 8–10 周 · 约 33h
学什么
选一个：FineBI 个人免费版（国内岗更认）或 Power BI Desktop（免费）。做一个「城市 × 技能 × 薪资」交互看板。
为什么值得单独花 3 周
BI 全样本溢价 +3.0K、要求率 53.4%，而大多数人只停在"会用 Excel 画图"。能交付一个可交互看板，是应届生里最直观的差异点。
验收
能对着看板讲清楚：为什么这里用堆叠柱不用饼图、这张图回答什么业务问题、结论是什么。讲不清 = 没做完。
产出
作品集 #4：看板截图 + 3 分钟讲解稿。
阶段 4 · 统计与业务框架 + 打包投递第 11–12 周 · 约 22h
学什么
假设检验的基本逻辑、A/B 测试完整流程、指标体系怎么搭。学到能口述，不推公式。
验收
能口述一次 A/B 测试从设计到结论的全过程（分流 → 指标 → 样本量 → 显著性 → 决策）。
产出
简历 v1 + 三个作品集页面整理成一份在线文档链接。

④ 明确不学清单

砍掉数据理由省下的时间去哪
Excel 深挖（透视表以外）全样本溢价 −1.5K，太原 −1.0K。它出现在低薪岗里，是标配不是卖点。转到 BI
SPSS2016 年 33% → 2026 年 5%，十年崩塌。教材还在教，市场已经不用。转到 Python
机器学习 / 算法无经验者溢价仅 +0.3K；46 条算法岗多要求研究生或竞赛经历，投入产出比最差。转到实习经历
爬虫采数据ACS 需无犯罪证明；且本次已论证「不是不能，是不值」——风险收益严重不对等。—
Hive / 大数据栈要求率仅 15.1%，是「有经验后顺手学」的东西，不是入场券。实习后跟项目学

【建议 4】「会用 AI 工具」目前不但没有溢价，还略低于无 AI 要求的岗位（15.0K vs 16.0K）。 它正在变成人人都会的默认项 —— 强调它的岗位，往往是本身定价不高的岗位。 所以：要会用，但不要把「熟练使用 ChatGPT」写进简历技能栏当卖点。 正确用法是用它加速你学 SQL/Python（改语句、解释报错、造练习数据），但每一条产出必须自己跑通、能解释。
