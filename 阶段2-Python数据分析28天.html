D16把 JD 数据读进来，先"看"再"算"60′
  • pd.read_csv('data/jd_dataset_v3.csv', encoding='utf-8-sig') —— 统一带 utf-8-sig： 这个文件带 BOM，新版 pandas 能自动剥掉，但用 csv 模块或旧版 pandas 读会多出一个叫 ﻿id 的怪列。 读写都固定写它，一劳永逸

D21groupby：把报告里的技能频率表复现出来75′
  • skills 列是 SQL|Excel|数据分析 这种竖线分隔的字符串 —— 先 .str.split('|') 再 .explode() 拆成一人一行
  • 然后 groupby('技能').size() 计数，除以总数得到百分比

参考答案 + 实测输出
sk = real[['id','skills']].copy()
sk['skill'] = sk['skills'].fillna('').str.split('|')
sk = sk.explode('skill')
sk = sk[sk['skill'].str.strip() != '']
freq = (100 * sk.groupby('skill')['id'].nunique() / len(real)).round(1)
print(freq.sort_values(ascending=False).head(10))

  • 对照阶段一 D1–D4 的窗口函数笔记 —— transform 保留行数，agg 压缩行数，这个区别就是窗口函数 vs GROUP BY 的区别
  • 把这两句 SQL 也写出来做对照（AVG(salary) OVER (PARTITION BY dept)）
D23merge：把两张表拼起来60′
